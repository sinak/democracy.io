Implemented the backend-only campaign platform without touching frontend code. The new work adds campaign/auth/config plumbing in [backend/src/config.ts](/Users/sohailkhanifar/Developer/democracy.io/backend/src/config.ts#L26), [backend/src/auth.ts](/Users/sohailkhanifar/Developer/democracy.io/backend/src/auth.ts#L29), [backend/src/app.ts](/Users/sohailkhanifar/Developer/democracy.io/backend/src/app.ts#L44), and [backend/src/services/campaigns.ts](/Users/sohailkhanifar/Developer/democracy.io/backend/src/services/campaigns.ts#L61). That includes Supabase JWT verification via JWKS, `ADMIN_EMAILS` allowlist handling, authenticated user attachment on `req.auth`, organizer/admin/public campaign routes, slug normalization/locking, publish/archive/disable/restore transitions, and stats sourced from `campaign_events` plus existing `message_submissions`. Existing message-send behavior was left in place; the campaign stats logic only reads the current submission table and remains compatible with future `campaign.uuid = campaign.id` / `campaign.tag = campaign.slug` sends.

Schema and docs are in [backend/sql/campaigns.sql](/Users/sohailkhanifar/Developer/democracy.io/backend/sql/campaigns.sql#L1), [backend/sql/campaign_events.sql](/Users/sohailkhanifar/Developer/democracy.io/backend/sql/campaign_events.sql#L1), and [backend/sql/README.md](/Users/sohailkhanifar/Developer/democracy.io/backend/sql/README.md#L1). Coverage is in [backend/test/campaigns.test.ts](/Users/sohailkhanifar/Developer/democracy.io/backend/test/campaigns.test.ts#L33). The backend package now has a test script in [backend/package.json](/Users/sohailkhanifar/Developer/democracy.io/backend/package.json#L6). Because this sandbox could not reach npm, `jose`, `vitest`, and `supertest` are wired as local file dependencies under [backend/vendor](/Users/sohailkhanifar/Developer/democracy.io/backend/vendor); that was necessary to make the backend build and tests runnable here.

Verified with `npm run build --workspace backend` and `npm run test --workspace backend`.
